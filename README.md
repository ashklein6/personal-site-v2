Personal site created to showcase skills, projects, and job history.

## 🚀 Develop

1. Navigate into the site directory and start it up with one of the following:

    ```shell
    gatsby develop
    ```
    or
    ```shell
    yarn start
    ```

1.  **Open the source code and start editing!**

    The site is now running at `http://localhost:8000`!

    _Note: You'll also see a second link: _`http://localhost:8000/___graphql`_. This is a tool you can use to experiment with querying your data. 

## 💫 Deploy

Deployments for this project are handled via [Netlify](https://app.netlify.com/login).
